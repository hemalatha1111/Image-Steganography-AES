# Deep Learning-Powered Image Steganography For Key Security

A secure web-based application that protects cryptocurrency private keys using **Deep Learning**, **AES Encryption**, and **Image Steganography**.
The system encrypts sensitive private keys and intelligently hides them inside digital images using CNN-based steganography techniques, providing multi-layer security against cyber threats. 



## 🚀 Features

* 🔐 AES-based private key encryption
* 🖼️ Image steganography for hidden key storage
* 🧠 CNN-based intelligent embedding & extraction
* 🔓 Secure decryption and retrieval process
* 🌐 User-friendly React frontend
* ⚡ Flask backend with image processing support
* 🛡️ Multi-layer security for cryptocurrency key protection

## 📌 Project Workflow

1. User enters cryptocurrency private key
2. AES encryption secures the private key
3. User uploads a cover image
4. CNN-based steganography embeds encrypted key into image
5. Stego image is generated and stored securely
6. Hidden key is extracted using decoder model
7. Original private key is decrypted and recovered
